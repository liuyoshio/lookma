# Demo: turn a table into a chart

Monthly sightings at Driftwood Cove, a made-up beach, plus how many fish snacks Hands ate.

1. Open the table: `open -a Numbers demos/seal-chart/seal-sightings.csv`
2. Say: **"Make a column chart of the seals and sea lions by month."**
3. Watch it select the table, open Chart in the toolbar and pick a 2D column chart. Every step is marked on screen.

Variations:
- "Now make the fish snacks a line chart."
- "Give the chart a title: Seals at Driftwood Cove."
